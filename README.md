# AI-Based Fake News Detection

A desktop application that checks news headlines and gives one of three verdicts: REAL, FAKE or UNVERIFIED.

## Features
- ML model (TF-IDF + Logistic Regression)
- Rule-based fact-checking engine
- Live verification using Google News RSS
- News category detection
- History in SQLite and PDF export

## How to run
1. Install Python 3.9 or higher
2. pip install -r requirements.txt
3. python main.py
